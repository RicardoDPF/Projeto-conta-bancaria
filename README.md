#  Projeto Conta Bancária em Java

##  Sobre o projeto

Este projeto consiste em uma aplicação de simulação bancária desenvolvida em Java, com o objetivo de praticar conceitos fundamentais da linguagem e da Programação Orientada a Objetos (POO).

Atualmente, a aplicação permite criar uma conta bancária, escolher entre conta corrente e conta poupança e receber um bônus inicial de acordo com o tipo de conta selecionado.

##  Funcionalidades

- [x] Criação de conta bancária.
- [x] Escolha entre conta corrente e conta poupança.
- [x] Concessão de bônus inicial de acordo com o tipo de conta.
- [ ] Novas funcionalidades em desenvolvimento.

##  Tecnologias utilizadas

- **Java** — linguagem de programação utilizada no desenvolvimento.
- **GitHub** — controle de versão e armazenamento do código-fonte.

##  Objetivos de aprendizado

- Praticar os fundamentos da linguagem Java.
- Desenvolver a lógica de programação.
- Aplicar conceitos de Programação Orientada a Objetos.
- Aprimorar o uso do Git e do GitHub no gerenciamento de projetos.

##  Próximos passos

O projeto continuará sendo desenvolvido com a implementação de novas funcionalidades e melhorias na estrutura do código.
